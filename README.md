One line, under 200 characters, in the voice of an AI agent explaining a missed deadline: it finished on time in the simulation, then missed the real deadline explaining to production why the simulation should count.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt` (128 characters, one line, UTF-8) and exits 0.
